# 红杏云官网地址

**推荐：** [https://hongxing.space/](https://hongxing.space/)

先打开这一条。地址栏的主机名是 `hongxing.space`，再看套餐。这篇只推荐这一个域名。

搜「红杏云」时，不要用搜索广告里多出来的后缀。对上主机名再看套餐。

## 合理的核对

下单前按这个顺序看。四项都写在推荐地址的页面上，再付款。

| 顺序 | 看什么 | 怎样算合理 | 不建议 |
| --- | --- | --- | --- |
| 1 | 域名 | 地址栏整段和 `hongxing.space` 一致 | 多一个字母、换一个后缀、从广告跳进来 |
| 2 | 流量 | 页面写明每月额度、重置日、用完是限速还是断开 | 只写「不限」却不写重置日 |
| 3 | 客户端 | 从推荐地址下载，版本还在更新 | 先装来历不明的包才能看价格 |
| 4 | 退款 | 套餐页或付款页写明条件 | 只在私聊里口头答应 |

## 不建议

- 不建议从搜索广告或私聊里的「备用域名」进入。
- 不建议先装来历不明的安装包，再回来看价格。
- 不建议把聊天里的口头退款，当成页面上已经写明的规则。

套餐、流量和退款以推荐地址上的页面为准。不代收款，不发客户端，不列其他品牌。
